# Agent instructions when a CodexPro-compatible MCP is available

- Start local development work by opening the current workspace.
- Inspect before editing.
- Prefer tree/search/read for discovery and targeted source inspection.
- Use write/edit/apply-patch only inside the active workspace.
- Use allowlisted shell execution for tests, builds, or project scripts rather than file browsing.
- Use background run/status/cancel for long-running local work.
- Review changes before declaring completion.
- Use handoff/context tools for long or multi-agent work.
- Keep browser swarm coordination in Web Agent Swarm; keep repository execution in the local development MCP.
